# Chrome Bookmark List - 外部仕様書

## 概要

Chrome Bookmark Listは、Chromeブラウザの新しいタブでブックマークをフォルダ別に整理して表示し、履歴も検索できるChrome拡張機能です。ユーザーはブックマークを視覚的に管理し、素早くアクセスでき、さらに履歴機能で過去の閲覧記録も確認できます。

## 主要機能

### 1. ブックマーク表示機能
- **目的**: Chromeのブックマークをフォルダ構造に従って一覧表示
- **動作**: 新しいタブを開くと、ブックマークが自動的にフォルダ別に表示される
- **表示内容**:
  - フォルダ名とフォルダ内のブックマーク数
  - 各ブックマークのタイトル、URL、Favicon
  - 階層構造（親フォルダ → 子フォルダ → 孫フォルダ）
- **補足**:
  - タイトルが空のブックマークは、URL をタイトルとして表示する
  - 「モバイルのブックマーク」は表示しない

### 2. フォルダ展開・折りたたみ機能
- **目的**: 大量のブックマークを整理して見やすくする
- **操作方法**:
  - サブフォルダがあるフォルダ: フォルダヘッダーをクリックしてサブフォルダの表示/非表示を切り替え
  - ブックマークのみのフォルダ: フォルダヘッダーをクリックしてブックマークリストの表示/非表示を切り替え
- **視覚的表示**:
  - 📁（折りたたみ状態）/ 📂（展開状態）のアイコン表示
  - サブフォルダは薄紫色の背景で区別

### 3. ブックマークアクセス機能
- **目的**: ブックマークへの素早いアクセス
- **操作方法**: ブックマークリンクをクリック
- **動作**: 新しいタブでブックマークのページが開く
  - `Cmd/Ctrl` を押しながらのクリック、または中クリック: 新しいタブをバックグラウンドで開く（表示中のタブは切り替わらない）
  - `Shift` を押しながらのクリックは開かずに選択する（§13 参照）

### 4. リアルタイム検索機能
- **目的**: 大量のブックマークから目的のものを素早く見つける
- **操作方法**: ページ上部の検索ボックスに文字を入力
- **検索対象**: ブックマークのタイトルとURL
- **動作**:
  - 入力に応じてリアルタイムでフィルタリング（連続入力をまとめるため、入力が止まってから 0.3 秒後に反映する）
  - 該当するブックマークを含むフォルダのみ表示
  - 検索時は関連フォルダが自動展開

### 5. Favicon表示機能
- **目的**: ブックマークの視覚的な識別性向上
- **動作**: 
  - Chrome の `_favicon` API（`chrome.runtime.getURL('/_favicon/...')`）によるローカル取得
  - favicon が未保有の場合は Chrome の標準アイコン（地球儀）を表示
- **セキュリティ重視**: 外部APIサービスを使用せず、ホスト名の流出を防止

### 6. タブナビゲーション機能
- **目的**: ブックマークと履歴を1つのページ内でタブ切り替えして表示する
- **操作方法**:
  - ヘッダー右側のタブ（📚 ブックマーク / 🕐 最近の履歴 / 🗂 最近閉じたタブ / 📅 カレンダー）をクリックして表示を切り替える（タイトルと同じ行に配置）
- **動作**:
  - 選択中のタブはアクセントカラーでハイライト表示
  - 「最近の履歴」「最近閉じたタブ」「カレンダー」タブは選択時にデータを読み込む（遅延読み込み）
  - ブックマーク・最近の履歴・カレンダーの各タブはパネル上部に専用の検索バーを持つ（最近閉じたタブは検索なし。§9 参照）。タブを切り替えてもヘッダー・タブの位置は変わらない
- **アクセシビリティ**: `role="tablist"` / `role="tab"` / `role="tabpanel"` と `aria-selected` を付与

### 7. 最近の履歴タブ
- **目的**: 過去の閲覧履歴を確認し、再アクセスを容易にする
- **操作方法**:
  - 「🕐 最近の履歴」タブをクリックして表示する
- **表示内容**:
  - 過去7日間の履歴を最大50件、カード形式のグリッドで表示
  - 各履歴項目のタイトル、URL、Favicon
  - 最終訪問日時、訪問回数
  - 履歴項目のタイトルをクリックすると新しいタブで開く
- **検索機能**:
  - パネル上部の検索バーで履歴をフィルタリング
  - タイトルとURLの両方を検索対象とする
  - 大文字小文字を区別しない検索
  - リアルタイム検索（入力と同時にフィルタリング）
  - 検索語を入れたまま別のタブへ切り替えて戻っても、検索欄の語で絞り込んだまま表示する

### 8. カレンダー履歴タブ
- **目的**: 当月分の閲覧履歴を日毎かつ単位時間１時間単位で確認し、履歴情報の確認を容易にする
- **操作方法**:
  - 「📅 カレンダー」タブをクリックして表示する
- **カレンダー表示**:
  - 左側に当月のカレンダーを表示（幅380px）
  - 履歴がある日付には青い点のインジケーター表示
  - 今日の日付はアクセントカラーでハイライト
  - 選択中の日付はアクセントグラデーション背景で表示
  - 前月・次月ボタンで月を切り替え可能
- **タイムライン表示**:
  - 右側に選択した日の履歴を時間単位（1時間ごと）で表示
  - 時間単位のナビゲーションリンク（スティッキー表示）で素早く該当時間にジャンプ
  - 各時間帯セクションは古い順（時系列順）で表示
  - 日付選択時、タイムラインのスクロール位置は自動的にトップに戻る
  - 履歴項目のタイトルをクリックすると新しいタブで開く
- **ドメイン統計表示**:
  - 各時間帯セクションの下に訪問ドメインの統計を表示
  - ドメインごとの件数を、件数の多い順にソート
  - 件数は、その時間帯にあるそのドメインの履歴項目（URL）の数。同じ URL を何度訪れても 1 件と数える
  - 各ドメインのFaviconアイコンを表示（取得失敗時は🌐アイコン）
  - ドメイン名と件数をバッジ形式で表示
- **履歴アイテム表示**:
  - 各履歴項目のタイトル、URL、Favicon
  - 訪問時刻（HH:MM:SS形式）
  - 訪問回数
  - URLは長い場合に省略表記（...）で表示
- **検索機能**:
  - パネル上部の検索バーで履歴をフィルタリング
  - タイトルとURLの両方を検索対象とする
  - 大文字小文字を区別しない検索
  - リアルタイム検索（入力と同時にフィルタリング）
  - 検索時は時間単位のグルーピングを維持

### 9. 最近閉じたタブ機能
- **目的**: 誤って閉じたタブや再度確認したいタブを素早く復元する
- **操作方法**:
  - 「🗂 最近閉じたタブ」タブをクリックして表示する
- **表示内容**:
  - `chrome.sessions.getRecentlyClosed()` による最大約25件の一覧表示
  - 単体タブのみ対象（ウィンドウとして閉じたものは対象外）
  - 自拡張の New Tab ページは除外（Chrome が `chrome://newtab/` として記録したものを含む）
  - 同一 URL は最新（最も最近閉じたもの）のみ表示（重複排除）
  - 各タブのタイトル、ドメイン、favicon、閉じた日時（lastModified）を表示
- **復元動作**:
  - タブ項目をクリックすると `chrome.sessions.restore(sessionId)` により元の位置へ復元
  - 復元後は一覧を自動再読み込みする（復元した項目は一覧から消える）
- **検索機能**: 検索フィルタは無し（閉じたタブ件数は最大約25件程度のため）

### 10. ドラッグ&ドロップによる移動・並び替え機能
- **目的**: ブックマークとフォルダを直感的に移動・並び替えする
- **フォルダ間の移動**:
  - ブックマークアイテムをマウスでドラッグ
  - 移動先フォルダのヘッダー部分にドロップ
  - 複数選択したブックマークを掴んでドラッグすると、選択中の全アイテムを一括で移動できる
- **ブックマークの並び替え**:
  - ブックマークを別のブックマークの上にドロップすると、その位置へ並び替える（上半分にドロップで前、下半分で後ろ）
  - 同じフォルダ内でも、別のフォルダのブックマークの上でも使える（別フォルダの場合は、そのフォルダのその位置へ移動する）
  - 複数選択したブックマークは、表示順を保ったまままとめて並び替える
- **フォルダの移動・並び替え**:
  - フォルダのヘッダーをドラッグし、別のフォルダのヘッダーにドロップする
  - ヘッダーの上側 40% にドロップ: そのフォルダの前へ並び替え
  - 中央 20% にドロップ: そのフォルダのサブフォルダにする
  - 下側 40% にドロップ: そのフォルダの後ろへ並び替え
  - 自分自身と、自分の子孫のフォルダへはドロップできない
- **視覚的フィードバック**:
  - ドラッグ中: ブックマークに「dragging」クラスが適用され見た目変化
  - ドロップターゲット: フォルダヘッダーがハイライト表示
  - ドロップインジケーター: 「ここにドロップ」のテキスト表示
- **制限事項**:
  - ブックマークを、今あるフォルダのヘッダーへドロップしても移動しない（同じフォルダ内の並び替えは、上の「ブックマークの並び替え」で行う）
  - 一括移動時、掴んだ項目が既に移動先フォルダにある場合は、選択中の他の項目も含めて何も移動しない
  - 一括移動時、掴んだ項目が別のフォルダにある場合は、選択中の項目のうち既に移動先フォルダにあるものだけを移動対象から除外する
- **動作**: Chrome Bookmarks APIを使用してブックマーク・フォルダを実際に移動し、UIを自動更新。移動と並び替えは取り消せる（§17 参照）

### 11. キーボードショートカット機能
- **目的**: マウスを使わずにブックマークを操作できるようにする
- **対応ショートカット**:
  - `↑` / `↓`: フォーカスをブックマーク・フォルダ間で移動
  - `Enter`: フォーカスしているブックマークを開く / フォルダを展開・折りたたみ
  - `Delete` / `Backspace`: フォーカスしているブックマークを削除（確認ダイアログを表示。§14 参照）
  - `F2`: フォーカスしているブックマークを編集
  - `Cmd/Ctrl + F`: 現在表示中のタブの検索入力欄にフォーカス（検索欄の無いタブ〔最近閉じたタブ〕ではブラウザ標準の検索に委ねる）
  - `Cmd/Ctrl + Z`: 直前の破壊的操作を取り消す（Undo）
  - `Shift + F10`: フォーカスしている項目のコンテキストメニューを表示
  - `?`: キーボードショートカット一覧ヘルプを表示
  - `Esc`: ダイアログやコンテキストメニューを閉じる、複数選択を解除する
  - コンテキストメニューを開いている間: `↑` / `↓` でメニュー項目を移動、`Enter` で実行
- **入力欄での挙動**: 検索入力欄など編集要素にフォーカスがある場合、矢印キーや Delete などの単独キーショートカットは抑制し、標準動作を優先する
- **アクセシビリティ**: ブックマーク項目とフォルダヘッダは `tabindex="0"` と `role="treeitem"` を付与してフォーカス可能になっている

### 12. コンテキストメニュー機能
- **目的**: ブックマークとフォルダに対する操作を 1 か所から選べるようにする
- **開き方**: 右クリック / `Shift + F10` / タッチ端末では長押し（0.5 秒）
- **ブックマークのメニュー**:
  - 開く: 表示中のタブで開く
  - 新しいタブで開く
  - バックグラウンドで開く
  - URLをコピー
  - 編集（§14 参照）
  - 削除（§14 参照）
- **フォルダのメニュー**:
  - 展開する / 折りたたむ
  - 中のブックマークを全て新しいタブで開く（サブフォルダの中も含む。件数を表示）
  - グループにまとめて開く（§16 参照）
  - 新規サブフォルダ（§15 参照）
  - フォルダ名を変更（§15 参照）
  - フォルダを削除（§15 参照）
- **無効になる項目**:
  - 中にブックマークが無いフォルダでは「開く」系の項目を選べない
  - ブックマークもサブフォルダも無いフォルダでは「展開する / 折りたたむ」も選べない
  - 「ブックマーク バー」「その他のブックマーク」では名前の変更と削除を選べない
- **対象になるブックマーク**:
  - 「全て新しいタブで開く」「グループにまとめて開く」の対象と件数は、そのカードに表示されているブックマーク（サブフォルダの中も含む）
  - 検索で絞り込んでいる間は、絞り込み後に表示されているブックマークだけを対象にする（件数バッジと同じ数になる）
  - 「ブックマーク バー」のカードは、バー直下のブックマークだけを対象にする（バーの中のフォルダは別のカードとして並ぶため）

### 13. 複数選択と一括操作機能
- **目的**: 複数のブックマークをまとめて移動・削除する
- **選択方法**:
  - `Shift` を押しながらクリック: 直前にクリックしたブックマークからの範囲を選択
  - 選択中に修飾キーなしでクリック、または `Esc`: 選択を解除
- **ツールバー**: 1 件以上選択している間、「N 件選択中」と「移動」「削除」「選択解除」のボタンを表示
  - 移動: 移動先フォルダを選ぶダイアログを表示し、選択中のブックマークをまとめて移動
  - 削除: 確認ダイアログを表示し、選択中のブックマークをまとめて削除
- **ドラッグ**: 選択中のブックマークを掴んでドラッグすると一括で移動・並び替えできる（§10 参照）
- **同じ URL のブックマーク**: 選択はブックマークごとに持つ。同じ URL のブックマークが複数あっても別々に選択でき、一覧が描き直されても、選んだブックマークが選ばれたままになる

### 14. ブックマークの編集・削除機能
- **操作方法**: 各ブックマークの編集ボタン・削除ボタン、コンテキストメニュー、キーボード（`F2` / `Delete` / `Backspace`）
- **編集**: ダイアログでタイトル・URL・保存先のフォルダを変更する
  - 保存先のフォルダを変えて保存すると、そのフォルダへ移動する
  - タイトルと URL はどちらも必須。空のまま保存すると、ダイアログの中に「名前とURLは必須です。」と表示して保存しない（タイトルが空のブックマークも、編集するときはタイトルの入力が要る）
- **削除**: 確認ダイアログを表示してから削除する。確認ダイアログには、削除後 5 秒以内なら元に戻せることを表示する
- 編集と削除は取り消せる（§17 参照）

### 15. フォルダの作成・名前変更・削除機能
- **操作方法**: フォルダのコンテキストメニューから選ぶ
- **新規サブフォルダ**: ダイアログで名前を入力し、そのフォルダの中に作成する
- **フォルダ名を変更**: ダイアログで新しい名前を入力する
- **入力の検証**（どちらも、ダイアログを開いたまま中にエラー文を表示し、作成・変更しない）:
  - 名前が空、または空白だけのとき: 「フォルダ名を入力してください。」
  - 名前の変更で、同じ階層に同じ名前のフォルダが既にあるとき: 「同じ名前のフォルダが既に存在します。」
- **フォルダを削除**: 確認ダイアログを表示してから、中のブックマークとサブフォルダごと削除する。中身がある場合は件数を表示する
- **制限事項**: 「ブックマーク バー」「その他のブックマーク」は名前の変更も削除もできない
- 作成・名前変更・削除は取り消せる（§17 参照）

### 16. タブグループとして開く機能
- **目的**: フォルダ内のブックマークを、Chrome のタブグループ 1 つにまとめて開く
- **操作方法**: フォルダのコンテキストメニューの「グループにまとめて開く」
- **動作**:
  - フォルダ内（サブフォルダの中も含む）のブックマークをすべてバックグラウンドの新しいタブで開き、1 つのタブグループにまとめる
  - グループ名はフォルダ名。色はフォルダ名から決まり、同じフォルダなら毎回同じ色になる
  - 21 件以上を開く場合は、開く前に確認ダイアログを表示する
  - タブグループの API が使えない環境では、グループにまとめずに個別のタブとして開く
  - グループの作成に失敗したときは「エラー」ダイアログで知らせる（§17 参照）

### 17. 取り消し（Undo）と通知
- **目的**: 誤った操作をすぐに元へ戻せるようにする
- **通知**: 操作の結果を画面下部のトーストで表示する。取り消せる操作のトーストには「元に戻す」ボタンが付く
- **取り消し方**: トーストの「元に戻す」ボタン、または `Cmd/Ctrl + Z`
- **期限**: トーストが表示されている 5 秒間だけ取り消せる。取り消せるのは直前の 1 操作
- **対象**: ブックマークの編集・削除・移動・並び替え（一括操作を含む）、フォルダの作成・名前変更・削除・移動・並び替え
- **エラーの通知**: 操作の失敗は「エラー」ダイアログで知らせる（OK ボタンか `Esc` で閉じる）
  - 対象: ブックマークの編集・削除・移動・並び替え、フォルダの作成・名前変更・削除・移動・並び替え、タブグループの作成、「元に戻す」の失敗、最近閉じたタブの復元の失敗、操作しようとした対象（編集するブックマーク、名前を変える・削除するフォルダ）が既に無いとき
  - タブを開く操作（クリック、メニューの「開く」系、「全て新しいタブで開く」）、「URLをコピー」、そのほかのメニュー項目の失敗も同じく知らせる
  - 操作の後の一覧の再読み込みに失敗したときも知らせる（一覧は前の内容のまま残る）
  - 一括操作（ツールバーの「移動」「削除」と、複数選択のドラッグでの移動・並び替え）は、1 件も成功しなかったときに、失敗した件数を「エラー」ダイアログで知らせる（例: 「2 件のブックマークを移動できませんでした。」）。選んだブックマークが別の場所で既に削除されていた分も、失敗として数える
  - 編集やフォルダ作成などのダイアログで入力中に起きた失敗と入力の誤りは、そのダイアログを開いたまま、中にエラー文を表示する
  - 一括操作の一部だけが失敗したときは、残りを最後まで処理し、成功した件数と失敗した件数をトーストで知らせる（例: 「2 件を移動しました（1 件は失敗）」）。成功した分は取り消せる
- **並び順**: 取り消すと、元のフォルダの元の位置へ戻る。複数のブックマークをまとめて移動・並び替え・削除した場合も、元の並び順に戻る

## ユーザーインターフェース

### レイアウト
- **タブナビゲーション**: ヘッダーのタイトルと同じ行に配置したピル型タブでブックマーク／最近の履歴／最近閉じたタブ／カレンダーを切り替え
- **グリッドレイアウト**: ブックマークフォルダ・履歴項目がカード形式で配置
- **レスポンシブデザイン**: 画面サイズに応じて最適化（モバイルでは1カラム）
- **モダンなUI**: カードのホバーエフェクト、シャドウ効果、アクセントグラデーション
- **ダークモード対応**: OSの配色設定（prefers-color-scheme）に連動してライト／ダークを自動切り替え

### 操作性
- **直感的操作**: クリックベースのシンプルな操作
- **視覚的フィードバック**: ホバー効果、アイコン変化
- **高速レスポンス**: 軽量設計による快適な操作感

### アクセシビリティ
- **文字のコントラスト**: 文字と背景のコントラスト比は、ライト・ダークのどちらの配色でも WCAG 2 の AA（通常の文字で 4.5:1 以上、大きな文字で 3:1 以上）を満たす
- **ダイアログ**: `role="dialog"` と `aria-modal` を付け、見出しを読み上げ用の名前にする（`aria-labelledby`）。ダイアログの中のエラー文は `role="alert"` で、表示されたときに読み上げられる
- **「エラー」ダイアログ**: 開いたときに OK ボタンへフォーカスを移す
- **ダイアログを開いている間のキー操作**: 確認・編集・「エラー」・ショートカット一覧のどのダイアログでも、開いている間は §11 のショートカット（`↑` / `↓`・`Enter`・`Delete`・`F2`・`?`）が背後の一覧に働かない。`Esc` はダイアログを閉じる
- **フォルダの見出し**: 読み上げ用の名前に、画面に見えているフォルダ名・サブフォルダの数・ブックマークの件数を含める
- **自動検査**: axe-core による検査で違反 0 件を保つ（テストと実ブラウザの両方。`docs/TESTING_GUIDE.md` 参照）
- キーボード操作は §11、タブの role は §6 を参照

## 対応環境

### 必要条件
- **ブラウザ**: Google Chrome（Manifest V3対応版）
- **権限**:
  - `bookmarks`: ブックマークデータへのアクセス
  - `history`: 履歴データへのアクセス
  - `favicon`: Chrome内部のfavicon APIへのアクセス
  - `sessions`: 最近閉じたタブの取得と復元（`chrome.sessions` API）へのアクセス
  - `tabs`: `chrome.sessions` が返す閉じたタブの URL・タイトルの読み取りに必要
    （この権限が無いと Chrome が URL/タイトルを除去するため一覧を表示できない。
    開いているタブの監視には使用しない）
  - `tabGroups`: 「グループにまとめて開く」（§16）で、開いたタブをタブグループにまとめて名前と色を付けるために必要

### パフォーマンス
- **起動時間**: 高速な初期読み込み
- **メモリ使用量**: 軽量設計
- **レスポンス性**: スムーズなUI操作

## 制限事項

1. **Chrome専用**: Chrome拡張機能のため、他ブラウザでは使用不可
2. **権限必須**: ブックマーク、履歴、favicon、sessions、tabs、tabGroupsの権限が必要
3. **表示制限**: 極めて大量のブックマーク（数千個以上）では表示速度が低下する可能性
4. **履歴期間制限**:
   - 最近の履歴タブ: 過去7日間、最大50件
   - カレンダー履歴タブ: 当月分、最大10,000件
5. **カレンダー履歴の制限**: 月ごとに最大10,000件の履歴を読み込むため、非常に多くの履歴がある場合は一部が表示されない可能性

## セキュリティ

- **プライバシー保護**: ブックマーク・履歴データはローカルでのみ処理、外部送信なし
- **ホスト名保護**: 内部ネットワークのホスト名が外部サービスに送信されることを防止
- **外部依存なし**: 外部APIサービスを使用せず、完全に自己完結
- **権限最小化**: 上の「必要条件」に挙げた、機能に必要な権限のみ要求
- **安全な実装**: XSS対策としてHTMLエスケープ処理を実装
